# pizza delivery app

Project Title: Pizza Delivery App - Online Ordering System

Description: Pizza Delivery is an interactive, text-based pizza ordering app built with Python. The project is designed to demonstrate core programming concepts like conditional logic (if/else), user input handling, and quantity validation in a simple and practical way. The app simulates a real pizza delivery service where the user can choose size, quantity, and type.

Key Features:

*   Interactive Ordering System: A step-by-step flow where user choices directly affect the order.
*   Case-Insensitive Input Handling: Implemented using lower() method to ensure the app accepts SMALL, Small, small without errors, improving User Experience (UX).
*   Quantity Limit Control: Implemented validation using isdigit() to allow only 1 to 13 pizzas per order.
*   Error-Free Input Parsing: Solved common string conflicts by using alternate quote nesting to handle user inputs smoothly.
*   Clean Conditional Logic: Uses nested if/else statements to handle valid and invalid orders (Order Confirmed / Order Failed).

Technologies Used:

*   Language: Python 3.13
*   IDE: PyCharm
*   Concepts Covered: Variables, input(), print(), if/else, String Methods: lower(), isdigit()
